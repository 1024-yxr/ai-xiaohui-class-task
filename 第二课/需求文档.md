# 需求文档

## 1. 应用概述

- **应用名称**：随手记账
- **应用描述**：一款面向个人用户的网页记账工具，支持自定义账单类型、设置支出上限、管理单笔账单，并可按日、周、月、年维度汇总查看收支情况。

---

## 2. 用户与使用场景

### 2.1 目标用户
- 有日常记账习惯、希望管理个人收支的用户

### 2.2 核心使用场景
- 用户记录每日收支账单
- 用户自定义账单分类并设置支出上限
- 用户查看不同时间维度的账单汇总

---

## 3. 页面结构与核心功能

### 3.1 页面总览

```
记账应用
├── 账单列表页（首页）
│   ├── 账单列表展示
│   ├── 新增账单入口
│   └── 时间维度切换（日 / 周 / 月 / 年）
├── 账单详情 / 编辑页
│   ├── 查看单笔账单详情
│   ├── 编辑单笔账单
│   └── 删除单笔账单
├── 新增账单页
│   └── 填写账单信息并提交
├── 汇总统计页
│   └── 按日 / 周 / 月 / 年汇总收支数据
└── 账单类型管理页
    ├── 查看账单类型列表
    ├── 新增 / 编辑 / 删除账单类型
    └── 设置各类型支出上限
```

### 3.2 账单列表页（首页）

- 展示账单记录列表，每条记录显示：日期、账单类型、金额、备注（可选）
- 支持按日、周、月、年切换时间维度，列表随之筛选展示对应时间范围内的账单
- 提供「新增账单」入口按钮
- 提供跳转至「汇总统计页」和「账单类型管理页」的入口

### 3.3 新增账单页

- 填写字段：
  - 账单类型（从已有类型中选择，必填）
  - 收支方向（支出 / 收入，必填）
  - 金额（数字，必填，大于 0）
  - 日期（默认当天，可修改，必填）
  - 备注（文本，选填）
- 提交后保存至账单列表，返回首页

### 3.4 账单详情 / 编辑页

- 点击列表中任意一条账单，进入详情页
- 展示该账单的完整信息
- 支持编辑所有字段并保存
- 支持删除该条账单，删除后返回列表页

### 3.5 汇总统计页

- 支持按日、周、月、年切换统计维度
- 展示所选时间范围内：
  - 总收入金额
  - 总支出金额
  - 净结余（收入 - 支出）
  - 各账单类型的支出金额及占比
- 若某账单类型支出超出设定上限，在统计页中以醒目方式标注提示

### 3.6 账单类型管理页

- 展示当前所有账单类型列表
- 支持新增账单类型（输入类型名称）
- 支持编辑账单类型名称
- 支持删除账单类型（若该类型下存在账单记录，需提示用户确认后方可删除）
- 支持为每个账单类型单独设置「月支出上限」（数字，选填；不填则视为不限制）

---

## 4. 业务规则与逻辑

- 账单类型为全局配置，新增账单时从已有类型中选择
- 支出上限以「月」为单位统计，每自然月重置计算
- 支出上限超出判断：当某类型当月累计支出 ≥ 设定上限时，在汇总统计页触发超限提示
- 删除账单类型时，若该类型下存在历史账单，需弹出确认提示，用户确认后方可删除；删除后该类型下的历史账单类型字段显示为「已删除类型」
- 账单金额仅支持正数，最多保留两位小数
- 日期默认为当前系统日期，用户可手动修改为任意历史或未来日期

---

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 新增账单时金额为空或为 0 | 提示「请输入有效金额」，阻止提交 |
| 新增账单时未选择账单类型 | 提示「请选择账单类型」，阻止提交 |
| 删除含历史账单的账单类型 | 弹出确认弹窗，用户确认后执行删除 |
| 账单类型名称为空时提交 | 提示「类型名称不能为空」，阻止保存 |
| 支出上限输入非正数 | 提示「请输入大于 0 的数字」，阻止保存 |
| 当前时间维度下无账单数据 | 列表页显示「暂无账单记录」空状态提示 |

---

## 6. 验收标准

- 可成功新增、编辑、删除单笔账单，数据实时更新至列表
- 账单列表可按日、周、月、年正确筛选展示
- 汇总统计页可按日、周、月、年正确计算并展示收支汇总及各类型占比
- 账单类型可正常增删改，支出上限可正常设置
- 当月某类型支出超出上限时，汇总统计页有明确提示
- 所有必填项校验生效，异常情况有对应提示
- 账单数据持久化存储，刷新页面后数据不丢失
