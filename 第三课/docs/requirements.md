# 待办事项管理软件 (Todo Manager) 需求文档

## 1. 项目背景
本项目旨在开发一款轻量级、高效的待办事项管理工具，帮助用户记录、分类和追踪日常任务。系统采用前后端分离架构，确保良好的用户体验和数据持久化。

## 2. 技术栈
- **后端 (Backend):** Python (使用 FastAPI)
- **数据库 (Database):** SQLite (轻量级嵌入式数据库)
- **前端 (Frontend):** Vue.js 3 (Composition API) + Tailwind CSS
- **通讯方式:** RESTful API (JSON 格式)

## 3. 功能需求分析

### 3.1 核心功能 (MVP)
1.  **任务列表展示:** 首页展示所有未完成和已完成的任务。
2.  **添加任务:** 用户可以输入任务标题，快速添加新任务。
3.  **任务状态切换:** 点击任务复选框，可将任务在“待办”和“已完成”状态间切换。
4.  **删除任务:** 支持物理删除任务。
5.  **暗色系界面:** 全局支持暗色系主题 (Dark Mode)，提升视觉舒适度。
6.  **历史统计标签页:** 新增专门的统计视图，展示每日任务创建数量。
    - **只读属性:** 历史统计数据由系统根据任务创建时间自动生成，用户无法手动编辑或修改，确保数据真实性。

### 3.2 进阶功能 (Phase 2)
1.  **优先级设置:** 任务可标记为“高、中、低”优先级，并以不同颜色区分。
2.  **截止日期:** 支持为任务设置提醒日期。
3.  **任务分类/标签:** 用户可以自定义分类（如：工作、学习、生活）。
4.  **搜索与筛选:** 支持按关键词搜索任务，或按状态、优先级、分类进行筛选。
5.  **数据可视化:** 在历史统计中增加图表（如柱状图、折线图）展示完成率趋势。

## 4. 数据库设计 (SQLite)

### 4.1 `todos` 表结构
| 字段名        | 类型    | 约束           | 描述             |
| :------------ | :------ | :------------- | :--------------- |
| `id`          | INTEGER | PRIMARY KEY    | 任务唯一 ID      |
| `title`       | TEXT    | NOT NULL       | 任务标题         |
| `description` | TEXT    |                | 任务详细描述     |
| `status`      | INTEGER | DEFAULT 0      | 0: 待办, 1: 已完成 |
| `priority`    | INTEGER | DEFAULT 1      | 1: 低, 2: 中, 3: 高 |
| `category`    | TEXT    |                | 任务所属分类     |
| `due_date`    | TEXT    |                | 截止日期 (ISO 格式) |
| `created_at`  | DATETIME| DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at`  | DATETIME|                | 最后更新时间     |

## 5. API 接口设计

-   `GET /api/todos`: 获取所有任务列表
-   `POST /api/todos`: 创建新任务
-   `GET /api/todos/{id}`: 获取单个任务详情
-   `PUT /api/todos/{id}`: 更新任务信息（标题、状态等）
-   `DELETE /api/todos/{id}`: 删除任务

## 6. UI/UX 设计建议
-   **布局:** 顶部导航标签页切换（任务列表 / 历史统计）。
-   **暗色主题:** 采用深色背景 (`#111827`) 和浅色文字，关键操作使用蓝色高亮。
-   **交互:** 响应式布局适配桌面端和移动端；状态切换即时保存。
-   **风格:** 简洁的现代 UI 风格，使用 Tailwind CSS 实现。
